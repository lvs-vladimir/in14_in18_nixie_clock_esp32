# IN-14 / IN-18 Nixie Clock on ESP32

Прошивка для часов на газоразрядных индикаторах IN-14 или IN-18 с управлением через ESP32 и веб-интерфейсом.

## Features

- Точное время по NTP (настраиваемый сервер, часовой пояс)
- Веб-интерфейс на GyverPortal: главная, настройки, информация, прошивка, логи
- **Защита веб-интерфейса паролем** (логин скрыт, поле только для пароля)
- **Смена пароля через веб** (старый + новый пароль)
- **OTA-обновление** прошивки и файловой системы через браузер
- **Автопоказ данных**: посекундное циклическое отображение выбранных датчиков/тикеров
- **Настраиваемая NTP синхронизация** (вкл/выкл, интервал)
- **Забыть WiFi** (кнопка в настройках для очистки SSID/пароля)
- **Display Data**: настраиваемые слоты для отображения:
  - Температура (OpenWeatherMap / Narodmon)
  - Атмосферное давление
  - Влажность
  - Курс Bitcoin (CoinGecko)
  - Курс Ethereum (CoinGecko)
  - Курс USD/RUB
  - Дата (ДД.ММ.ГГ)
- **Эффекты смены цифр** (посекундно): Без / Последовательно / Плавно / Автоцикл
- **Автоматическая ротация эффектов** по таймеру (настраивается, 3–300 сек)
- **Анимации смены режимов**: LTR, RTL, To Center, Outward, Random, Even/Odd, Scroll, Random digit flip
- WS2812B RGB-подсветка (6 светодиодов, 20+ анимаций)
- **WS2812 по режиму дисплея** — отдельная анимация для времени и датчиков
- Автоматическая регулировка яркости WS2812 и индикаторов по датчику VEML7700 (настраиваемые диапазоны)
- Работает на двух ядрах ESP32 (FreeRTOS)

## Hardware

| Компонент | Назначение |
|-----------|-----------|
| ESP32 Dev Board | Микроконтроллер |
| IN-14 / IN-18 (6 шт) | Газоразрядные индикаторы |
| HV5522 | High-side драйвер анодов (через HSPI) |
| VEML7700 | Датчик освещённости (I2C) |
| WS2812B (6 шт) | RGB светодиоды подсветки |
| MOSFET + BL pin | ШИМ-регулировка подсветки |

## Pinout

| Pin | Назначение |
|-----|-----------|
| GPIO2 (BL) | ШИМ подсветки |
| GPIO5 | CS для VSPI |
| GPIO12 (HSPI_MISO) | HSPI MISO |
| GPIO13 (HSPI_MOSI) | HSPI MOSI |
| GPIO14 (HSPI_SCLK) | HSPI Clock |
| GPIO15 (HSPI_SS) | HSPI Chip Select (HV5522 LE) |
| GPIO16 | WS2812 Data + N/C |

## Web Interface

Устройство доступно по адресу `http://IN18-NIXIE.local/` (или по IP).

### Страницы
- **Главная** — курсы BTC/ETH/USDRUB, датчики VEML7700 и OWM, Display Data (слоты автопоказа + эффекты смены цифр)
- **Настройки** — NTP (сервер, зона, вкл/выкл, интервал синхронизации), WiFi (SSID/пароль + кнопки Подключить/Забыть), смена пароля, API ключи OWM/Narodmon, язык, секунды
- **Подсветка** — WS2812 вкл/выкл, анимация, интервал случайной смены, яркость, VEML7700 диапазоны яркости для WS2812 и для индикаторов
- **Инфо** — системная информация
- **Прошивка** — OTA обновление (firmware + filesystem)
- **Логи** — системные логи с автообновлением каждые 3 сек

### Пароль по умолчанию
`admin`

## Display Modes (State Machine)

Переключение между временем и датчиками работает как конечный автомат:

```
MODE_TIME → MODE_TIME_OFF → MODE_SENSOR_ON → MODE_SENSOR_HOLD → MODE_SENSOR_OFF → MODE_TIME_ON → MODE_TIME
```

- **MODE_TIME**: отображение текущего времени (ЧЧ:ММ:СС)
- **MODE_SENSOR_HOLD**: отображение выбранного датчика на заданное время
- Переходы сопровождаются анимациями (off-эффект → on-эффект)

## Digit Change Effects

Настраиваются на главной странице (карточка Данные дисплея):

| Режим | Описание |
|-------|----------|
| Автоцикл | Автоматическая смена эффекта по таймеру (0→1→2→0…) |
| Без | Мгновенная смена цифр, без анимации |
| Последовательно | Цифры последовательно переключаются до нужного значения |
| Плавно | Плавный кроссфейд старой и новой цифры |

В режиме «Автоцикл» можно задать интервал смены (3–300 секунд).

## Mode Transition Animations

Настраиваются на главной странице:

| Режим | Описание |
|-------|----------|
| Случайная | Случайный выбор каждый раз |
| Слева направо | Последовательное выключение/включение слева направо |
| Справа налево | Справа налево |
| К центру | От краёв к центру |
| От центра | От центра к краям |
| Случайные лампы | В случайном порядке |
| Чётные потом нечётные | Сначала чётные позиции, потом нечётные |
| Нечётные потом чётные | Сначала нечётные, потом чётные |

## Brightness Control

Яркость WS2812 и газоразрядных индикаторов регулируется автоматически по датчику VEML7700.
Для каждого из 4 диапазонов освещённости (WS2812) и 6 диапазонов (индикаторы) настраиваются min/max люкс и значение яркости.

Значения по умолчанию для индикаторов IN-18:

| Lux | Яркость |
|-----|---------|
| 0–12 | 15 |
| 15–47 | 40 |
| 50–97 | 80 |
| 100–297 | 150 |
| 300–697 | 200 |
| 700–15000 | 255 |

Все диапазоны настраиваются через веб-интерфейс.

## Build & Flash

Установите [PlatformIO](https://platformio.org/):

```bash
pio run -e esp32dev --target upload
pio device monitor --port /dev/ttyACM1
```

OTA (по DNS-имени):
```bash
pio run -e esp32dev --target upload --upload-port IN18-NIXIE.local
```
